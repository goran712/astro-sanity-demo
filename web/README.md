# web

The static Astro site: pages, section components, vanilla CSS and GROQ queries (`src/lib/queries.ts`).
Copy `.env.example` to `.env`, then run `npm install`.
Commands: `npm run dev` (local server), `npm run build` (static output in `dist/`), `npm run preview`.
See the [root README](../README.md) for the full project overview.
